# 🪓 Viernes 13 — Eres mi viernes 13... TE AMO LIZET

Sitio web interactivo y romántico ambientado en la leyenda de **Viernes 13 (Jason Voorhees / Camp Crystal Lake)** en la entrada, y en un **Modo Spotify de lujo** con letra sincronizada en tiempo real, girasoles y montañas, dedicado con todo el amor a Lizet.

---

## 🔐 Clave de Acceso
* Contraseña: `viernes13` (permite mayúsculas o minúsculas)

---

## ✨ Características y Mejoras de Diseño
1. **Pantalla de Entrada con Estética Jason Viernes 13:**
   - Máscara de hockey de Jason Voorhees estilizada en vector SVG con remaches, ventilación y marcas rojas triangulares de la saga.
   - Brillo de ojos carmesí y aura de niebla cinematográfica de Camp Crystal Lake.
   - Tipografía neón de película de terror con giro romántico: *"Dicen que el viernes 13 es de miedo y maldición... pero contigo se convirtió en mi mayor bendición."*
   - Campo de contraseña protegido con opción para ver/ocultar y feedback animado.
2. **Bienvenida Romántica:**
   - Saludo cariñoso a Lizet y dedicatoria conectada con la canción.
3. **Reproductor Modo Spotify (Optimizado para Celular y PC):**
   - **En PC:** Vista dual simultánea (reproductor a la izquierda y letras en vivo a la derecha) en armonía.
   - **En Celular:** Barra de pestañas táctil (`[ 🎵 Reproductor ]` y `[ 📜 Letra en Vivo ]`) con mini-reproductor flotante para mantener el control mientras lees la letra.
   - Portada oficial con aura ambiental.
   - Frase destacada: `eres mi viernes 13... TE AMO LIZET 🌻`.
   - Botón de "Me Gusta" con lluvia interactiva de corazones y girasoles.
   - Controles Spotify completos: Play/Pausa, adelantar y retroceder 10s, repetición y barra de progreso táctil.
4. **Letra Sincronizada en Vivo (Karaoke Spotify):**
   - Sincronización exacta de los 37 versos.
   - El verso que suena se agranda, se ilumina en blanco/oro y se auto-centra suavemente en pantalla.
   - Interactivo: toca cualquier verso para saltar a ese segundo de la canción.
5. **Carta Final de Amor:**
   - Dedicatoria romántica personalizada basada en los versos más emotivos.
6. **Efectos Visuales:**
   - Canvas con pétalos de girasol cayendo, destellos dorados y bruma tenue.

## 🚀 Cómo Subir a GitHub y Activar GitHub Pages

### Paso 1: Inicializar Git en esta carpeta
Abre una terminal (PowerShell o Git Bash) en esta carpeta y ejecuta:
```bash
git init
git add .
git commit -m "Viernes 13 - Para Lizet (Modo Spotify & Jason Theme)"
```

### Paso 2: Crear el repositorio en GitHub
1. Entra a [github.com](https://github.com) y crea un nuevo repositorio (por ejemplo, `viernes13-lizet`).
2. Copia la URL de tu repositorio (por ejemplo: `https://github.com/TU_USUARIO/viernes13-lizet.git`).

### Paso 3: Subir los archivos
En tu terminal ejecuta:
```bash
git branch -M main
git remote add origin https://github.com/TU_USUARIO/viernes13-lizet.git
git push -u origin main
```

### Paso 4: Activar GitHub Pages
1. En tu repositorio en GitHub, ve a **Settings** > **Pages**.
2. En **Branch**, selecciona **`main`** y la carpeta **`/(root)`**.
3. Haz clic en **Save**.
4. En pocos segundos tendrás tu enlace público para enviárselo a Lizet.
