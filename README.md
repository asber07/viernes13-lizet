# 🌻 Viernes 13 — Eres mi viernes 13... TE AMO LIZET

Sitio web interactivo y romántico en **Modo Spotify** con letra sincronizada en tiempo real, ambientado con girasoles, atardecer y montañas, dedicado con amor para Lizet.

---

## 🔐 Clave de Acceso
* Contraseña: `viernes13` (permite mayúsculas o minúsculas)

---

## ✨ Características Principales
1. **Pantalla de Entrada (Portal de la suerte):**
   - Ilustración con anillo animado de girasol y luz estelar.
   - Campo de contraseña seguro con botón para mostrar/ocultar clave.
   - Detección de errores animada.
2. **Bienvenida Emotiva:**
   - Saludo cariñoso a Lizet y cita de la canción.
   - Entrada fluida que activa el audio cumpliendo las políticas de autoplay de navegadores móviles.
3. **Reproductor Modo Spotify:**
   - Foto de portada de la canción (girasoles y montañas) con aura ambiental y sombra dinámica.
   - Título y artista oficial: **Marcos Menchaca — Viernes 13**.
   - Mensaje especial destacado: *"eres mi viernes 13... TE AMO LIZET"*.
   - Botón de "Me Gusta" con animación interactiva y lluvia de corazones.
   - Controles completos de reproducción: barra deslizable de tiempo, Play/Pause, retroceder y adelantar 10s, botón de repetición.
4. **Letra Sincronizada en Vivo (Karaoke Spotify):**
   - 37 versos sincronizados automáticamente con el archivo `letra/letra.lrc`.
   - El verso activo se amplía, se ilumina en blanco/dorado y se centra suavemente en pantalla.
   - Versos anteriores y posteriores con opacidad atenuada tipo Spotify.
   - Interactivo: haz clic en cualquier línea para saltar a ese segundo exacto.
5. **Carta Final de Amor:**
   - Dedicatoria romántica personalizada basada en los versos más hermosos de la canción.
6. **Partículas Interactivas:**
   - Fondo canvas con pétalos de girasol cayendo y destellos dorados.

## 🚀 Cómo Subir a GitHub y Activar GitHub Pages

### Paso 1: Inicializar Git en esta carpeta
Abre una terminal (PowerShell o Git Bash) en esta carpeta y ejecuta:
```bash
git init
git add .
git commit -m "Viernes 13 - Para Lizet (Modo Spotify)"
```

### Paso 2: Crear el repositorio en GitHub
1. Entra a [github.com](https://github.com) y crea un nuevo repositorio (por ejemplo, `viernes13-lizet`).
2. Copia la URL de tu repositorio (por ejemplo: `https://github.com/TU_USUARIO/viernes13-lizet.git`).

### Paso 3: Subir los archivos
En tu terminal ejecuta:
```bash
git branch -M main
git remote add origin https://github.com/TU_USUARIO/viernes13-lizet.git
git push -u origin main
```

### Paso 4: Activar GitHub Pages (En 30 segundos)
1. En tu repositorio de GitHub, entra a la pestaña **Settings** (Configuración).
2. En el menú de la izquierda, haz clic en **Pages**.
3. En la sección **Build and deployment** > **Branch**:
   - Selecciona la rama **`main`**.
   - Selecciona la carpeta **`/ (root)`**.
   - Haz clic en **Save**.
4. ¡Listo! En unos segundos tendrás tu enlace público (por ejemplo: `https://TU_USUARIO.github.io/viernes13-lizet/`) para enviárselo a Lizet.
